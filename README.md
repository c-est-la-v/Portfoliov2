# Portfolio — Creative XR Developer

Static bilingual (IT/EN) portfolio, ready for GitHub Pages. No build step required.

## Open locally
Extract the entire ZIP, keeping `index.html`, `style.css`, `script.js`, `assets/` and `media/` together. Open `index.html` in a modern browser. If your browser blocks local video playback, serve the folder locally (`python -m http.server 8000`) and browse to `http://localhost:8000`.

## Publish on GitHub Pages
Upload the **contents** of this folder to the repository root, then select **Settings > Pages > Deploy from a branch**, main, root. The paths are relative, so they also work on a project Pages URL.

Seven self-hosted MP4 videos play inline when their cover is clicked. HACCP footage is intentionally silent and marked as a work-in-progress preview. The Marina Militare card includes only a strongly blurred still; no project video is published, and the site does not solicit further confidential details.

Before making the site public, ensure that even the blurred Marina Militare still and all project descriptions are authorized for publication.
